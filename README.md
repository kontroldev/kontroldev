## 📚 Proyecto destacado: Viñe

**Una app para iPhone y iPad publicada en la App Store.**

Viñe ayuda a catalogar una colección de cómics y leer archivos propios sin conexión. Permite seguir los números de cada serie e importar cómics en **CBZ, PDF y EPUB de cómic**.

[Ver en la App Store](https://apps.apple.com/es/app/vi%C3%B1e/id6809613945) · [Explorar el código y la arquitectura](https://github.com/kontroldev/PanelMax-App)

**Algunos detalles de ingeniería:**

- **Swift 6 y SwiftUI:** interfaz nativa y comprobación estricta de concurrencia.
- **SwiftData:** persistencia local y esquema preparado para migraciones.
- **Lectores CBZ, PDF y EPUB de cómic:** implementaciones separadas bajo una interfaz común, con progreso de lectura y doble página en iPad.
- **Swift Testing y CI:** pruebas de la lógica de colección, importación y lectores; GitHub Actions ejecuta pruebas en simulador y compila la configuración Release.
- **Accesibilidad:** soporte para Dynamic Type y VoiceOver en las pantallas principales.

*PanelMax es el nombre interno del proyecto de Xcode y del repositorio de Viñe.*
